# No-mas-grupos-random

<p align="justify">
DataSquad crea perfiles donde destacas tus habilidades dominantes y publicas la destreza técnica que le falta al equipo. El algoritmo hace match con el estudiante ideal. Al final, el sistema de calificación de compañeros evalúa el compromiso real de cada uno, asegurando el proyecto y filtrando a los clásicos estudiantes que no aportan al equipo.

### Problema que resuelve
<p align="justify">
Muchos estudiantes tienen problemas con integrantes que no colaboran en trabajos grupales. Los grupos suelen formarse al azar y no existe un sistema que mida el compromiso real.

### Funcionamiento de la plataforma

La plataforma permite que cada estudiante cree un perfil con sus habilidades y fortalezas. Después de cada proyecto, los integrantes pueden calificarse entre sí según su participación y compromiso.

El sistema utiliza esta información para recomendar estudiantes compatibles y formar grupos más equilibrados y eficientes.

### Funciones principales
* Crear perfiles estudiantiles
* Registrar habilidades
* Sistema de calificaciones
* Recomendación de compañeros
* Historial de desempeño
### Público objetivo

Estudiantes universitarios y colegios.
